# gakkel-fleet-dashboard
Interface de monitoring et visualisation temps réel pour le système **Gakkel** de détection de formes par ROV.

## 🎯 Objectif

Application serveur Java/Vaadin permettant de :
- Recevoir les détections depuis le Raspberry Pi
- Afficher en temps réel les formes détectées
- Visualiser des statistiques et timeline
- Monitorer le statut du système embarqué

## 🛠️ Stack Technique

- **Langage** : Java 25
- **Framework Web** : Vaadin 25.x
- **Backend** : Spring Boot 4.x
- **Build** : Maven
- **Communication** : REST API + WebSocket
